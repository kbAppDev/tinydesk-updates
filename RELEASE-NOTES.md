# Flare Tools · Image Compressor 2.1.0

- The image queue and compression controls share one workspace again. A compact Flare Tools header replaces the sidebar.
- Thumbnails load as you scroll. The queue shows the original size, compressed size and savings for each image.
- Four starting presets cover everyday images, product photos, website images and email attachments.
- Save your own combinations of quality, output format and maximum size. You can recall, update, rename or delete each saved preset.
- Reopening the app restores your last preset or custom settings. Upgrading from 2.0.1 carries forward your compression choices and output folder.

Run **Flare-Image-Compressor-Setup-2.1.0.exe** to install or upgrade on Windows. To use the portable edition, extract the portable ZIP and open **FlareImageCompressor.exe**.
